# Day 8 Reflection

The most difficult concept in this course was system design, especially understanding how different parts of an application work together. At first, concepts such as APIs, databases, servers, scaling, caching, and load balancers seemed like separate topics. I found it difficult to understand why a system would need different components and when each one should be used. I overcame this by breaking the design into smaller steps: first understanding the requirements, then estimating the traffic, designing the API, designing the database, and finally adding architecture components only when there was a specific problem to solve.

The part of my capstone that I would improve is the backend and database integration. I would make the application more complete by connecting the frontend to a real backend and database so that user data and activity are stored reliably. I would also improve error handling and make sure that users can only access their own information.

The next thing I want to learn is how to build real backend applications using Node.js and Express and connect them to PostgreSQL. I also want to become more comfortable writing SQL queries and understanding authentication, APIs, transactions, and deployment. These skills will help me move from designing systems on paper to building complete applications that can support real users.
